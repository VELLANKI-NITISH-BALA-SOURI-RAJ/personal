## why
Students cannot practise DSA consistently, so it is difficult to track progress.
## what
A web application where students can add solved problems, select difficulty level, track daily streaks, and view dashboard progress.
# Goal
Help students maintain DSA consistency and measure their improvement.

## Features
- Problem entry form
  - Problem name
  - Difficulty
  - Platform
  - Date of solving
- Streak tracking
  - Current streak
  - Longest streak
- Dashboard
  - Total problems solved
  - Problems solved by difficulty
    - Easy count
    - Medium count
    - Hard count

## Tasks
1. Create problem entry form.
2. Store problem data.
3. Calculate streak.
4. Display dashboard.

## Validation

### Problem Name
- Required
- Minimum 3 characters

### Difficulty
- Must be Easy/Medium/Hard

### Solved Date
- Cannot be a future date

## Success Criteria
- User can add problems.
- Streak updates correctly.
- Dashboard displays accurate statistics.
- Invalid inputs are rejected.
